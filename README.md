## 年付到底省多少，怎么自己算

年付的省法是把 12 个月的钱一次付掉，换一个更低的有效月价。DMIT 各系列的具体折扣幅度我没法给出一个可靠数字，因为价格随活动变动，写死反而误导。

算法不复杂。结算页把周期选成年付，记下总价，除以 12 得到有效月价；再把周期切到月付，看月价乘以 12 是多少，两个数一比，差额就是年付省下来的钱。用第三方文章里的历史价格做这个比较没有意义，活动一换就对不上了。

年付的真实成本也不是首年那一个数字。它是首年价，加上后面每一年续费价乘以你要用的年数。三年期的账，得按三年算。

## 退款条款逐条看：3 天、30 天和不退款清单

DMIT 的退款规则分三档，编号在条款 19.1 到 19.3。

**全额退款（19.1）**：购买不超过 3 天，并且虚拟机上用掉的流量不超过 30GB，扣除支付网关收取的交易手续费后全额退。

**部分退款（19.2）**：购买不超过 30 天。退款按实际支付金额计算，如果按已用流量折算出的价值更高，就按剩余流量退；否则按剩余服务时间退。

**不予退款（19.3）**：同一系列产品已经退过 3 次；遭受 DDoS 攻击；以「网络状况不佳」为由；以「IP 地理位置原因」为由；任何形式的滥用造成的损失；在违反服务条款的前提下单方面向支付公司发起争议；IP 在部分地区不可用但已用流量超过 3GB。

对年付买家最要紧的是最后这一档里的两条。「网络状况不佳」和「IP 地理位置原因」都不在退款理由内，意思是国内访问慢、某个服务解锁不了、IP 在某个地区不通，这些都不能作为退年付的依据。3 天窗口又卡了 30GB 流量，装系统、跑测速、搬数据，一天就可能用掉不少。

条款里还有一句值得记住：如果发现 IP 在全球范围内都无法访问，要在购买当天第一时间联系销售部门。这种情况有时效，拖过当天就难说了。

另一条容易忽略的是 chargeback。单方面向支付公司发起争议被明确列进不退款情形，真出问题时先开工单，别直接拒付，否则连协商的余地都没了。

## 常见问题

**年付 VPS 能退款吗？**
看商家。DMIT 是 3 天内且流量不超过 30GB 全额退（扣网关手续费），30 天内按剩余流量或剩余时间折算部分退，超过 30 天以及 19.3 列出的情形不退。

**3 天全额退款有什么坑？**
30GB 流量上限、支付网关手续费不退、同一系列累计 3 次退款后不再受理。DDoS 和「网络状况不佳」也不在退款范围。

**年付比月付便宜多少？**
自己算。结算页切换计费周期，年付总价除以 12，再和月价对比。不要拿第三方文章里的历史价格做比较。

**续费会涨价吗？**
没有看到续费同价的公开承诺。以账单页显示的续费金额为准，购买时记下来。

**国内访问选哪个机房？**
电信线路为主看 LAX.Pro，移动线路或流量大看 LAX.EB。想要亚太低延迟看香港和东京，HKG.Pro 全系 1Gbps、流量 0.5–6TB，消耗大的选 HKG.EB 或 HKG.T1。
